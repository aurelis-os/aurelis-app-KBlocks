# KBlocks AppImage

**Version:** 26.08.2-1 | **Architecture:** x86_64 | **License:** MIT

---

## Description

KBlocks is a classic falling blocks game by KDE. The objective is to stack the falling blocks to create horizontal lines without any gaps. When a line is completed, it disappears, and the blocks above fall down. The game ends when the blocks reach the top of the playing area.
